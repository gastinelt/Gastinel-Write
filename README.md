# Gastinel Write — Monorepo des déclinaisons

Ce dépôt regroupe les nouvelles déclinaisons de **Gastinel Write**, en sous-dossiers séparés (décision de Théo : pas de dépôts Git distincts, contrairement à ce qui était envisagé au départ).

Le C++20/OpenGL original (`gastinel-write-public`) reste un projet séparé, terminé et stable — il n'est pas touché ici.

## Sous-dossiers

- [`rust-tauri/`](./rust-tauri) — déclinaison Rust + Tauri, PC modernes, système d'extensions prévu.
- [`c-legacy/`](./c-legacy) — déclinaison C ultra-léger, PC anciens (2000-2009), sans extensions.

## Identité produit (transverse, inchangée dans toute déclinaison)

- Nom : **Gastinel Write** (pas de sous-marque par version).
- Slogan : **"L'écriture, sans fard."**
- Mention légale : **"Gastinel. Logiciel libre de droit."**

Chaque sous-dossier a son propre README documentant les décisions d'architecture prises et celles encore ouvertes.
